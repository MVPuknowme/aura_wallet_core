Aura-Core / SkyGrid Edge Command Center

Draft, validate, package, and review Helm/Kubernetes and L2 artifacts before any wallet signing or Web3 execution.

Helm status

helm/aura-core-autodrill is reviewed with lint, template render, and Kubernetes dry-run commands.

L2 scripts

JavaScript modules under scripts/l2/ prepare, sign, submit, and verify without automatic execution.

Operator review

Payloads are visible and redacted before final approval, signing, or submission.

Receipts

Transaction hashes and receipt status can be attached after explicit Web3 submission.

  • Prepare Helm values.
  • Generate route intent.

2. Validate

  • Run lint and dry-run checks.
  • Inspect generated payloads.

3. Package

  • Create reviewable artifacts.
  • Summarize operator commands.

4. Execute

  • Use wallet only for explicit approval.
